# Сайт «Терра» — авторская керамика для ресторанов

Обычный статический сайт: HTML + CSS + JavaScript. Сборка не нужна, можно выкладывать как есть.

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | Вся страница: 13 блоков, как в макете Figma |
| `privacy.html` | Политика конфиденциальности (шаблон — проверьте с юристом перед запуском) |
| `css/style.css` | Стили, цвета, шрифты, мобильная версия |
| `js/main.js` | Меню, форма, анимации (библиотека GSAP подключается с CDN) |
| `assets/img/` | Фото, сжатые для быстрой загрузки |
| `assets/favicon.svg` | Иконка сайта |
| `serve.ps1` | Локальный просмотр на компьютере (не нужен на хостинге) |

## Посмотреть сайт на своём компьютере

```
powershell -ExecutionPolicy Bypass -File serve.ps1
```

Потом открыть в браузере `http://localhost:5173`.
Добавьте `?noanim` в адрес, чтобы отключить анимации (удобно для проверки вёрстки).

## Подключить форму заявки

1. Зайти на https://web3forms.com, ввести почту, на которую должны приходить заявки, и получить ключ (Access Key).
2. Открыть `js/main.js` и вставить ключ в строку `const WEB3FORMS_KEY = '';` между кавычками.
3. Пока ключа нет, форма показывает надпись «Демо-режим» и ничего не отправляет.

## Выложить в интернет (Vercel, бесплатно)

1. Зарегистрироваться на https://github.com и https://vercel.com (вход в Vercel — через GitHub).
2. Создать на GitHub репозиторий и загрузить в него содержимое этой папки.
3. В Vercel: **Add New → Project → Import** этот репозиторий → **Deploy**. Настройки менять не нужно.
4. Сайт будет доступен по адресу вида `имя-проекта.vercel.app`.
5. Свой домен: в Vercel **Settings → Domains** → добавить домен и прописать DNS-записи у регистратора.

## Что заменить перед реальным запуском

- Контакты, адрес, имя мастера, ИП и ИНН — сейчас это вымышленные данные-примеры.
- Отзывы, кейсы и цифры — тоже примеры. Для настоящего сайта нужны реальные (отзывы — с согласия авторов).
- Фото сгенерированы Figma AI — для настоящего бизнеса лучше заменить на фото реальных изделий.
